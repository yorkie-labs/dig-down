# Dig Down

얼음 아래로, 강아지의 굴착 모험. Mr. Driller 스타일의 브라우저 퍼즐 액션 게임입니다.

**플레이:** https://yorkie-labs.github.io/dig-down/

- 조작: ←→ 이동 · ↑↓ 방향 · Space/Z 망치 · R 재시작 · Esc 일시정지 · M 소리 (터치: 왼쪽 조이스틱 + 망치 버튼)
- 개발: `npm install` → `npm run dev` → http://localhost:5173/3d.html · 테스트 `npm test`

## 크레딧
- 배경 3D 소품: [Polyfork](https://polyfork.dev) 무료 저폴리 모델 (런타임에 Polyfork CDN에서 불러옴, 파일은 저장소에 포함하지 않음)
- 폰트: [Jua](https://fonts.google.com/specimen/Jua) (SIL Open Font License)
- 엔진: [three.js](https://threejs.org)

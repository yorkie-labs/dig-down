# 20261025 Mr. Driller 형식 전면 재설계

출처: Mr. Driller 공식 매뉴얼(PlayStation Classic), Wikipedia. 수치는 매뉴얼 기준.
이전 설계(못 깨는 바위 + 곡괭이 1회 + X 구조)는 Mr. Driller 규칙으로 대체한다.

## 원작 규칙 (매뉴얼 확인)
- 4방향(상/하/좌/우) 드릴. 좌/우 이동, 옆에 한 칸 높이 단이 있고 위가 비면 올라탐.
- 같은 색 블록은 덩어리를 이루고, 하나를 뚫으면 덩어리 전체가 사라짐.
- 지지 없는 블록은 흔들린 뒤 떨어짐. 떨어지다 **지지된 같은 색 블록을 만나면 붙어서 멈춤**.
- 떨어져 붙은 결과 같은 색 4칸 이상이면 드릴 없이 사라짐 → 연쇄.
- 갈색 X 블록: **5번** 쳐야 깨짐, 깨면 공기 **-20%**.
- 공기: 목숨마다 100%에서 시작, 계속 감소. 공기 캡슐(걸어 들어가 획득)로 회복(약 20%).
  30% 미만이면 해골 + 경보, 0%면 목숨 -1.
- 블록에 깔리면 목숨 -1. 기본 목숨 3.
- 100m마다 레벨. 아케이드 목표 500m. 깊을수록 블록이 빨리 떨어짐.
- 점수: 블록 1개 뚫기 10점 / 4칸 소멸 블록당 30점 / 캡슐 100, 200, 300…(점점 증가)
  / 골 도달 시 남은 목숨당 30,000점 / 시간 보너스.

## 이 게임에 적용 (설계)
- 필드: 9칸 폭(원작 비율, 길 선택지 증가). 색 4종 + X 블록 + 공기 캡슐.
- 목표: 500m, 100m마다 레벨 (레벨이 오르면 색 팔레트/배경 변경, 흔들림 시간 단축, X 비율 증가).
- 레벨 경계: 각 100m 마지막 줄에 공기 캡슐 2개 확정 배치. (빈 휴식층은 그 위 전체가 낙하하므로 폐기)
- 목숨을 잃으면: 공기 100% 회복, 두더지 위 3칸 블록 제거(즉시 다시 깔리는 것 방지), 무적 1.5초.
- 점수, 공기 게이지(원형 대신 세로 막대), 해골 경고(30% 미만, 화면 테두리 붉게 깜빡임).
- 결과 화면: 깊이/점수/시간, 최고 기록(localStorage).
- 비주얼: 기존 크레용 스타일 유지 (두더지 주인공 = 우리 차별점).
- 제외(나중에): 서바이벌/타임어택 모드, 언더그라운더, 리플레이, 이름 입력.

## 조작 (확인 필요)
- 안 A (원작식): 방향키 = 이동/드릴 방향 지정, 스페이스/Z = 드릴. 터치: 십자 + 드릴 버튼.
- 안 B (현재식): 방향키로 블록을 밀면 바로 드릴. 버튼 하나 적음, 대신 옆 블록 위로 올라탈 때와 충돌.

## Review
- 사용자 확인: 문서대로 진행, 조작은 원작식(이동 + 드릴 버튼).
- 구현: 9칸, 4색, X 블록(5타/공기 -20%), 공기(1.2%/s, 캡슐 +20%), 30% 미만 해골·파란 얼굴·붉은 테두리,
  100m 레벨(팔레트/흙색 변경, 흔들림 10→6틱), 500m 골, 점수(드릴 10/소멸 30/캡슐 100·200·300…/목숨당 30,000),
  리스폰(공기 100%, 머리 위 3칸 제거, 무적), 결과 화면 + 최고기록(localStorage, try/catch).
- 테스트 21개 통과, tsc/build 통과, 콘솔 에러 없음.
- 브라우저 확인: 드릴, 4칸 소멸(+240/+270), X 블록 표시, 캡슐, 깊이 마커, 공기 바, 레벨 배너.
- 조정: 4색이라 덩어리가 너무 커서 군집 확률 하향(좌 0.25, 위 0.38). 레벨 배너가 두더지를 가려 화면 상단 20%로 이동.
- 검증 중 이슈: 입력 없이 게임이 진행되는 것처럼 보였으나, 키 이벤트 로그 결과 자동화 도구/사용자 입력이었고 코드 문제 아님.
- 미확인: 공기 0 → 사망, 레벨 2 이상, 500m 클리어 화면은 테스트로만 검증. 터치 패드 실기기 미확인.
  공기 소모율/캡슐 빈도 밸런스는 실플레이로 조정 필요.

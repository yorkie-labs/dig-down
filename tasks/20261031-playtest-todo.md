# 사용자 테스트 반영 (2026-10-31)

받은 피드백:
1. 조여 오는 긴장감이 부족하다
2. 쉽다가 어려워지는 구간이 필요하다. 게임 속도가 처음엔 느리다가 빨라지고, 스테이지를 넘어가면 다시 느려졌다가 빨라지는 리듬
3. 블록을 깰 때 타격감이 부족하다

## 계획
### A. 속도 리듬(톱니형) — 규칙 (`game.ts`)
- [x] 100m 레벨 안에서 블록 흔들림과 낙하가 빨라지고(×1.0→1.35), 공기 소모는 여유에서 빠듯함으로 바뀜(×0.95→1.6, 곡선 p^1.6)
  - 처음엔 둘을 한 값(0.85→1.3)으로 묶었는데, 봇 시뮬레이션에서 느린 낙하(1 미만)가 오히려 흔들리는 블록을 기다리게 해 질식이 늘었다(아케이드 클리어율 30%→15%). 그래서 두 템포를 분리했다
- [x] 청록 클리어 줄을 지나 다음 레벨이 시작되면 템포가 0.85로 리셋(숨 돌리기). 레벨마다 기본 난이도는 원래대로 오르므로 '오르는 선 위의 톱니'
- [x] 렌더러의 흔들림과 낙하 보간도 같은 템포를 따름. 테스트 갱신, 톱니 테스트 추가
- [x] 시뮬레이션 melt 추적기가 같은 틱 안의 녹음→착지→팝을 놓치던 문제를 pop 이벤트의 melt 루트로 보완
- [x] 봇 확인(greedy 20시드): 아케이드 30%, 오로라 15%로 변경 전과 같음. 동굴은 45%→75%로 약간 쉬워짐. 무지성 봇은 대부분 질식으로 죽음 → 레벨 후반의 공기 압박이 실제로 작동

### B. 긴장감 — 연출 (`sfx.ts`, `main3d.ts`)
- [x] 절차 생성 배경 음악: BPM 96→160이 레벨 안 템포를 따름. 강도가 오르면 킥, 하이햇, 아르페지오 순으로 추가. 공기가 40% 미만이면 더 빨라지고 경보음. 효과음보다 우선순위가 낮음
- [x] 레벨의 60% 지점에서 '⚡ 빨라진다!' 신호(떠오르는 글자와 흔들림) 1회

### C. 타격감 — 연출
- [x] 블록 깰 때마다 월드 히트스톱 30~80ms(덩어리 크기 비례), 화면 흔들림 0.07~0.16, 망치가 닿은 면에 만화풍 임팩트 별(흰 섬광에서 노랑으로), 파편 1.5배, 진동 12ms
- [x] 깨는 소리에 얼음 '쩍' 크런치와 몸통 쿵(폰 스피커 대역) 추가
- [x] X 블록 칩핑에도 히트스톱, 임팩트 별(남은 HP가 적을수록 커짐), 진동

## 리뷰
- 테스트 181개 통과(1개 건너뜀), 타입 검사 통과
- 브라우저 확인: 70m에서 '⚡ 빨라진다!' 신호, X 블록 칩핑, 콘솔 에러 없음. 임팩트 별은 0.13초짜리라 캡처로는 잡지 못했고 코드로 확인
- 남은 것: 실제 사람 플레이로 손맛 확인. 히트스톱은 연속 망치질 속도를 30ms씩 늦추니 답답하면 낮추기. 음악 음량과 레이어 기준값 조정

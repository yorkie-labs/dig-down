# 20261101 Backdrop review (배경 3안 비교)

사용자: "뒤에 깔려있는 배경이 문제인거 같아. 디자인이 전체적으로 3D로 표현하면 괜찮으려나?"

판단: 배경(양옆 절벽, 판 구멍)만 3D 후보로 본다. 주인공은 2D 잉크 스프라이트를 유지한다
(3D 강아지 `puppy.glb`는 Tripo 비상업 라이선스, 스프라이트는 이미 블록과 같은 잉크 규칙).

- [x] `?bg=muted`: 그림 절벽·판 구멍을 셰이더로 채도·대비를 낮춤 (`mutePainting`)
- [x] `?bg=3d`: `src/backdrop3d.ts` 절차 생성 로우폴리 지층 암벽
  - 지층 2~4.5 단위, 덩어리 2~4.5 단위, 덩어리마다 돌출량 다름 → 위로 향한 턱 = 눈, 아래 = 그늘
  - 2톤 툰 램프(소품과 같음), 화면 기준 1.6px 잉크(`LineSegments2`), 깊이 틴트는 `cliffMats`로 공유
  - 세그먼트 24단위, 한쪽 3장을 카메라 따라 이어 붙임. 판 구멍은 어두운 남색 그라데이션
- [x] 비교 스크린샷 (지표면·130m·250m × 데스크톱·휴대폰) → https://claude.ai/artifact/AHKQ7DJbe4Vejcmh6Qa2L8
- [x] 3D 2차 (사용자: "3D를 조금 더 개선할 수 있으려나?" 전에 시작): 지층 경계가 x에 따라 오르내림(±0.75), 덩어리 1.5~6 단위, 판 구멍 너머 어두운 먼 암벽(z -5~-7)
- [x] 3D 3차: 덩어리별 면 기울기, 키 라이트 기준 3단계 셀 톤(버텍스 색), 안쪽일수록 어둡게, 얼음 덩어리 18%, 아래를 향한 턱에 잉크 고드름
- [x] 3D 암벽을 기본값으로 (사용자가 3D 방향을 묻고 3D 추가 개선을 요청한 흐름에 따름. 푸시 전이라 되돌리기 쉬움)
  - 옛 그림 절벽은 `?bg=paint`로 남김(비교용), 톤 다운 안(`?bg=muted`)은 진단용이라 제거
  - 기본값에서는 절벽 그림 텍스처를 받지 않음. `textures/cliff-*`는 PWA 프리캐시에서 제외(~670KB, `cliff-left/right.png`는 원래 미사용)
  - 확인: smoke·input 시나리오 통과, 기본값/`?bg=paint` 130m 화면 정상, `npm test`·`npm run build` 통과
- [x] 사용자 확정("3D 전환하자"): 그림 절벽 완전 삭제
  - 코드: `?bg=paint` 분기, 그림 절벽 메시·`fitCliffs`, 안 쓰이던 `farTex`(시작마다 512px 캔버스를 그리던 죽은 코드). `cliffMats` → `wallMats`
  - 파일: `public/textures/cliff-{left,right}{,-tile}.png` 4장(~670KB), `tools/crop_textures.py`의 절벽 저장 줄과 `seamless()`, 프리캐시 예외
  - 확인: 2560×1080 초광폭에서도 암벽이 화면 끝까지 닿음(타이틀·130m), smoke·input 시나리오 통과, `npm test`·`npm run build` 통과, `dist/textures`에 절벽 없음

## 관찰
- 데스크톱은 배경이 화면 절반 이상. 휴대폰은 플레이 중 보드가 폭을 거의 채워 배경은 판 구멍·타이틀에서만 보임
- draw call은 세 안 모두 플레이 중 18~31개로 비슷
- 3D 시제품의 남은 손질(2·3차에서 반영): 턱 가장자리 불규칙, 덩어리 크기 변화, 먼 층 암벽, 면 셰이딩, 얼음다움

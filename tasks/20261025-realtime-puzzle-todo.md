# 20261025 Realtime Puzzle Elements (실시간 액션 + 선택 압박)

문제: 아래만 누르면 클리어됨 → 파기 비용 없음, 옆으로 갈 이유 없음, 위험 약함.
방향: 실시간 액션 유지. "시간 압박 속에서 고르게 만들기".

## 후보 요소
1. 공기 게이지: 시간에 따라 줄어듦. 0이 되면 목숨 -1 후 다시 채움.
   - 공기 캡슐: 가끔 블록 사이에 있음. 닿으면 공기 +. 돌아갈지 말지 선택.
2. 단단한 바위 비용: 회색 돌을 깨면 공기 크게 소모 → 피해서 돌아갈 이유.
3. 4칸 이상 합쳐지면 자동 소멸: 떨어진 덩어리가 같은 색과 합쳐 4칸 이상이 되면
   흔들린 뒤 터짐 → 연쇄. 중력을 노려서 쓰게 됨 (동시에 위험도 커짐).
4. 점수/연쇄 표시: 터뜨린 칸 수, 연쇄 배수. 깊이 + 점수로 재도전 동기.

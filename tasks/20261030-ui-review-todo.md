# UI 디자이너 리뷰 (2026-10-30)

직접 캡처해서 봤다. 데스크톱(타이틀, 도감, 플레이 HUD, 저공기, 결과)과 폰(390×844 플레이·결과, 타이틀 4가지 크기).

## P0: 바로 고침
- [x] 폰 결과 카드의 "스테이지 선택" 버튼이 조이스틱과 망치 버튼 밑에 깔림 → 결과 카드와 타이틀에서는 터치 패드를 숨김 (`body:has(#overlay:not([hidden])) #pad`)

## P1: 정보 구조, 가독성
- [x] 1. 결과 카드가 9줄짜리 표라 한눈에 안 읽힘. 위계를 세운다: 큰 결과(별 ★★☆ 크게, 깊이·점수 큰 숫자) → 한 줄 원인·팁 → 다음 목표 → 세부(시간, 최고 기록)는 작게. 제목 'GAME OVER'만 영어 → '아쉬워요!' / '도착!'
- [x] 2. 결과 카드 버튼: 졌을 때 "다음 스테이지 ▶ 눈송이 언덕"(이미 깬 쉬운 곳)이 주 버튼보다 위에 뜸. 졌으면 [다시 하기]가 주, 이겼으면 [다음 스테이지]가 주. 터치 기기에서는 (R)(S)(N) 키 표기 숨김
- [x] 3. 공기 바 글자 'AIR 21%'가 어두운 바 위에서 안 보이고 영어. 바 밖 왼쪽에 아이콘(🫧)과 숫자를 두고, 30% 미만이면 바 전체가 맥동. 바도 조금 더 두껍게
- [x] 4. HUD 알약 3개(하트·점수·깊이)와 메달 지표 줄, 음소거 버튼이 제각각 떠 있음. 상단 바 한 줄로 정렬(좌: 하트, 가운데: 깊이 m 크게, 우: 점수), 메달 지표는 공기 바 아래 작은 칩으로. 음소거는 일시정지 메뉴 안으로(폰에서 결과 카드 모서리와 겹침)
- [x] 5. 데스크톱 플레이 중 하단 키보드 힌트 바가 계속 떠 있음 → 처음 20초나 첫 판에만 보이고 사라지게
- [x] 6. 토스트(규칙·팁)가 보드 위 상단을 가리고 길면 2줄로 늘어남 → 한 줄 요약 + 아이콘, 위치는 공기 바 바로 아래로 고정, 최대 폭 제한

## P2: 타이틀, 도감
- [x] 7. 데스크톱 타이틀: 목록이 보드 한가운데 떠서 반투명한 잠긴 행 뒤로 블록 색이 비쳐 지저분함. 목록 카드에 단색 배경 패널(크림 + 잉크 테두리)을 깔고 행은 불투명하게. 잠긴 행은 투명도 대신 회색 톤
- [x] 8. 별 합계 '★ 0/21' 알약이 목록 위 오른쪽에 따로 떠 있음 → 목록 패널 헤더에 통합("스테이지 · ★ 0/21"). '📖 도감 · 배지 0/13'은 너무 작음 → 아이콘 버튼으로 키우고 음소거와 같은 줄에
- [x] 9. 선택한 행의 조건 텍스트(12~13px)가 작아 읽기 어려움. ★1/★2/★3을 칩으로 보여 주고 달성한 것은 채움
- [x] 10. 도감: 닫기 버튼이 없음(아무 키나 탭으로만 닫힘), 한 장에 너무 많음(달력·꾸미기·배지 13개). 상단 탭 3개(배지 / 꾸미기 / 오늘의 코스) + 우상단 ✕. 잠긴 꾸미기는 실루엣 아이콘
- [x] 11. 타이포그래피 단계가 너무 많음(12, 13, 14, 15, 17, 20, 42 + clamp). 스케일을 정리: 12 / 14 / 17 / 22 / 32 / 로고

## P3: 일관성, 접근성
- [x] 12. 색 토큰 통일: 잉크 #1b2238과 #2b2a4a가 섞여 있고, 크림 rgba 값이 제각각. CSS 변수(--ink, --cream, --gold, --sky)로 정리
- [x] 13. 터치 영역: 음소거(약 36px)와 도감 버튼이 44px 미만 → 44px 이상 (완료: 타이틀 🔊·⏸·📖 44px, 스테이지 행·일시정지·결과 버튼 min-height 44px)
- [x] 14. 깔림 경고 '!'와 위험 펄스가 빨강 하나라 색약에게 약함 → 모양(!, 흔들림)이 함께 있는지 점검
- [x] 15. 일시정지 화면: '일시정지 — 탭해서 계속'만 있음 → 계속 / 다시 하기 / 스테이지 선택 / 소리 버튼이 있는 메뉴로

## 리뷰

배치 b1~b6에서 구현하고 배치마다 따로 리뷰했다. 마지막에 전체 화면을 한 번 더 확인했다(데스크톱 타이틀, 폰 SE·14·Android, 가로 844×390, 플레이 HUD, 저공기, 콤보, 토스트, 일시정지, 승리·패배 카드, 도감 탭 3개). 15개 항목 모두 끝났다.

### 바뀐 것
- **결과 카드 (1, 2):** 제목 '아쉬워요!' / '도착! 🎉'. 위계는 별 → 깊이·점수 큰 숫자 → 원인 한 줄 → 다음 목표 → 소식 → 작은 세부 순서. 졌으면 [다시 하기], 이겼으면 [다음 스테이지]가 금색 주 버튼이고 맨 앞에 온다(DOM 순서도 같다). 진 뒤에는 `nextStageAfter(p, id, false)`가 더 쉬운 스테이지로 돌아가지 않는다(테스트 추가). 터치 기기에서는 (R)(S)(N)을 숨긴다. 짧은 가로 화면용 압축 배치를 넣었다.
- **HUD (3, 4):** 크림색 상단 바 한 줄(하트 / 깊이 m + Lv / 점수 + ⏸). 공기 바 밖에 '🫧 공기 N%' 라벨을 두고, 30% 미만이면 빨강으로 맥동한다(모션 줄이기 설정이면 꺼짐). 메달 지표는 공기 바 아래 칩. 음소거는 타이틀에만 두고, 플레이 중에는 일시정지 메뉴에서 켜고 끈다.
- **힌트·토스트 (5, 6):** 키보드 힌트는 플레이 누적 20초 뒤 사라지고, 사라진 상태를 저장한다. 토스트는 아이콘 + 한 줄이고 공기 바 바로 아래에 고정된다. 팁 10개와 스테이지 설명 7개를 한 줄로 줄였다. `role=status`를 달았다. 복사 확인은 공유 버튼 라벨이 바뀌는 것으로 알린다.
- **타이틀 (7, 8, 9):** 단색 크림 `#stage-panel` 안에 불투명한 행을 둔다. 잠긴 행은 회색 톤이다. 헤더는 '스테이지 · ★ N/21'. 📖 버튼은 44px로 🔊 옆에 있다. 선택한 행은 ★1/★2/★3 칩으로 보여 주고, 달성한 칩은 채우고 ✓를 붙인다.
- **도감 (10):** ✕ 버튼, 탭 3개(배지 / 꾸미기 / 오늘의 코스). 잠긴 꾸미기는 점선과 실루엣으로 보이고 필요한 배지를 적었다. Esc·B로 닫고 ←→로 탭을 바꾼다. Tab 포커스는 도감 안에서만 돈다.
- **타이포·색 (11, 12):** 글자 크기를 12/14/17/22/32 다섯 단계로 정리했다(로고와 별은 예외). `src/style.css`의 `:root` 토큰(--ink, --cream, --gold, --sky 등)으로 색을 통일했다. 잉크는 보드와 같은 `#2b2a4a` 하나다.
- **접근성 (13, 14, 15):** 버튼, 탭, 스테이지 행은 모두 44px 이상이다. 깔림 경고는 꼬리 달린 말풍선 + 잉크 테두리 '!' + 흔들림이라 색만으로 알리지 않는다(모션 줄이기 설정이면 고정). 일시정지는 계속 / 다시 하기 / 스테이지 선택 / 소리 메뉴다.
- **최종 리뷰에서 고친 것:** 한국어가 단어 중간에서 줄바꿈되던 문제. 스테이지 조건('클/리어'), 도감 합계('0/일'), 꾸미기 설명('누/적', '스/테이지')에서 보였다. `3d.html`의 `body`에 `word-break: keep-all; overflow-wrap: break-word`를 한 번 걸고, 결과 카드에 따로 있던 `keep-all` 두 개는 지웠다.

### 남은 것
- 잉크는 `#2b2a4a`로 정했다. `#1b2238`을 원하면 `--ink` / `--ink-rgb`(`src/style.css`)와 `INK`(`src/main3d.ts`)만 바꾸면 된다.
- 시계 스테이지에서도 공기 바가 100%로 보인다(전부터 그랬다). 숨길지 결정이 필요하다.
- 크림색 위 🫧 아이콘이 흐리다. 글자 라벨은 잘 읽힌다.
- 흔들리는 블록의 지터와 캔버스 공기 펄스는 모션 줄이기 설정을 아직 따르지 않는다.
- 도감에서 잠긴 배지는 아직 `opacity: .5`다(카드가 불투명해서 비침은 없다). 오늘의 코스 탭은 아래가 비어 보인다.
- 가로 844×390에서는 선택한 스테이지 행이 커서 목록이 1.5행쯤 보이고 스크롤된다.
- 실제 터치 기기(coarse pointer)에서는 확인하지 못했다. 키 표기 숨김은 주입한 스타일로만 봤다.
- 테스트 시간 초과: 기계 부하가 클 때(load 20~35) `game.test.ts`와 `sim.test.ts`의 긴 테스트가 기본 5초 제한을 넘는다. 로직 문제는 아니다.

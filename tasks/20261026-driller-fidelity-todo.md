# 20261026 Mr. Driller 원작 수치 반영

조사: 서브에이전트(매뉴얼, 개발자 좌담회 Arcadia 2000.4, StrategyWiki, 일본어 위키, 나무위키,
Mr. Driller G 프레임 측정, 팬 위키). 신뢰도: P=1차/측정, F=팬 자료, NF=못 찾음.

## 반영
- [x] 화면 12줄 (F) — 필드 9칸은 이미 일치 (F)
- [x] 레벨별 색 수 4/3/2/4/3 (P: 레벨별 프리셋 / F: 순서)
- [x] 캡슐 +23% (P: 개발자 발언, G 측정. 20%는 화면 표시값)
- [x] X 블록끼리 붙고 4개 이상이면 소멸, 드릴은 맞은 1개만 깸 (P/F)
- [x] 흔들림 약 1초 (F, 레벨 1 기준). 이후 단축은 우리 선택
- [x] 낙하 속도 6.667→12칸/s (G 측정, 중간 레벨은 보간)
- [x] 공기 소모 1.32→2.16%/s (G 측정값 차용 — 원작 1편 수치 NF)
- [x] 레벨 끝 청록 줄: 뚫으면 위 전부 제거 + 레벨×1000점 (F). 캡슐 재생성(원작 버그)은 미구현
- [x] 캡슐 빈도 ~84개/1000m (F), X 블록 한 줄 건너 한 줄, 깊을수록 캡슐을 X가 둘러쌈 (F, 확률은 우리 선택)
- [x] 목숨 보너스는 현재 목숨 포함 (F: 무사망 3목숨=90,000) — 기존 구현 유지
- [x] 로직 틱 1/60초로 변경(흔들림/낙하를 초 단위로)

## 추가: 점수 1UP (사용자 선택: 2편 방식)
- [x] 100,000점 도달 시 목숨 +1 (Mr. Driller 2 GBA 500m 스테이지 기준, F)
- 1편 매뉴얼에는 1UP 규칙 없음. 2편의 추가 기준점(20만…)과 거리 1UP 수치는 못 찾음 → 기준점 1개만
- 상한 없음(1회뿐이라 불필요). `EXTEND_SCORES` 배열로 기준점 추가 가능
- 점수 증가는 `addScore`로 통일(골인 목숨 보너스는 게임 종료 시점이라 제외)
- 테스트 26개 통과, 새 탭 로드/플레이 콘솔 에러 없음. 실제 10만 점 도달은 테스트로만 확인

## 미반영 / 원작 수치 없음
- 리스폰 방식: 자료 충돌(제자리+위 제거 vs 100m 지점 복귀) → 제자리 유지
- 무적 시간 NF, 시간 보너스 기준 시간 미확인(1차 자료 없음) → 미구현
- 연쇄 배수 없음(원작과 동일)

## Review
- 테스트 25개 통과, tsc/build 통과, 콘솔 에러 없음.
- 브라우저(새 탭, 합성 키 이벤트): 4초 드릴 → 32m, 3연쇄, X 덩어리 외곽선, 캡슐 표시,

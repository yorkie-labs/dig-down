# 20261027 3D 렌더링 실험판 (SPIKE, 버릴 전제)

목적: 트윗 파이프라인의 Blender + Tripo 단계를 실험하기 전에, 2D 게임을 3D로 렌더링하는 게
이 게임에 어울리는지 눈으로 판단.

## 결정
- `game.ts`는 그대로 공유, 렌더러만 Three.js로 새로 (`3d.html`, `src/main3d.ts`). 2D 버전은 손대지 않음.
- 스파이크라 테스트 추가 없음. 입력/HUD 코드는 main.ts에서 복사(공유는 채택 시 정리).
- 표현: 툰 셰이딩(3단계 램프) + 뒤집힌 외곽(inverted hull) 검은 선, 같은 색 이웃 쪽으로 큐브를 늘려 덩어리를
  한 조각처럼 보이게. 두더지는 도형 조합(나중에 Tripo 모델로 교체). 조명: 반구광 + 그림자 태양광 + 두더지 헤드램프,
  레벨이 깊을수록 어둡게.

## Review
- 브라우저: 61m까지 정상 렌더, 그림자/덩어리/X 블록 텍스처/드릴 방향 확인, 콘솔 에러 없음. 기존 테스트 28개 통과.
- 발견한 버그(수정): InstancedMesh 경계를 처음 한 번만 계산해 깊이 내려가면 블록이 전부 사라짐 → frustumCulled=false.
- 조정: 헤드램프가 너무 밝아 두더지가 주황색으로 보여 12 → 5.
- 다음: 사용자 판단(3D로 갈지). 가면 Tripo로 두더지 모델(스케치 이미지 입력), Blender 설치 필요.

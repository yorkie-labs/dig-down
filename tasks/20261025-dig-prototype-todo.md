# 20261025 Dig Prototype (회색 박스 1단계)

목표: "Make it exist first" — 스케치(두더지가 색 블록 갱도를 파고 내려가는 게임)를
에셋 없이 플레이 가능한 상태로 만든다. 판단 기준: 5분 해봤을 때 재미있는가?

## 핵심 규칙 (C. 파고들기 액션)
- 7칸 폭 갱도, 깊이 60칸. 바닥(마지막 줄)까지 내려가면 클리어.
- ←/→: 빈칸이면 이동, 블록이면 파기 (위가 비어 있으면 한 칸 올라타기).
- ↓/↑: 아래/위 블록 파기.
- 색 블록: 같은 색으로 연결된 덩어리째 한 번에 부서짐.
- 회색 돌: 각 칸 독립, 3번 쳐야 부서짐.
- 지지 잃은 덩어리는 잠깐 흔들린 뒤 낙하. 두더지 위로 떨어지면 목숨 -1 (총 3).

## 기술
- Vite + TypeScript + Canvas 2D (외부 엔진 없음)
- `src/game.ts` 순수 로직 (고정 tick), `src/main.ts` 렌더/입력
- Vitest로 로직 테스트

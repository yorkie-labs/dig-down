## Review
- 구현 요약
  - 카메라: 시야각 32° → 14°, 거리 자동(거의 직교), 기울기/좌우 흔들림 최소
  - 블록: 인스턴스 속성 aMask(8방향), onBeforeCompile로 앞면에 덩어리 둘레 잉크(칸당 0.045) + 안쪽 모서리 + 위 베벨/아래 그림자 띠,
    옆면은 잉크색 쪽으로. 역외곽 메시 2개 제거(드로우콜 감소). 판은 fog:false.
  - 팔레트: 채도 낮추던 mute 제거, 동화책 4색(분홍/노랑/청록/파랑) 레벨별
  - 톤/조명: ACES → Neutral, 그림자 맵 끔, 반구광 1.8·태양 2.6(three 물리 조명 /π 감안)
  - 배경: 뒷벽/옆벽 상자 제거 → 먼 얼음 동굴 판(z=-14), 눈 턱·고드름 있는 잉크 절벽(z=-1.5, 좌우 대칭), 앞쪽 고드름 실루엣(z=8),
    레벨별로 어둡게 틴트. 오로라를 지표 화면 안으로.
  - 강아지: MeshBasic(이중 조명 제거), 키 1.04칸, 깊이별 약한 틴트. 드릴은 잉크 그린 납작한 카드.
- 플레이 중 조정: 블록이 어두워(빛이 약함) 조명 상향 / 절벽이 화면 밖 → 안쪽으로 / 눈 턱·고드름이 이빨처럼 보여 축소 / 오로라 과노출 → 투명도 0.3
- 확인: 브라우저에서 지표·21m 화면, 잉크/베벨/절벽/강아지 확인, 콘솔 에러 없음, 테스트 28개·빌드 통과
- 아직: 동작 그림(옆모습·드릴질), 깊은 레벨(2~5) 실플레이 확인, 픽셀 모드와의 조합 점검, 모바일 성능 측정
